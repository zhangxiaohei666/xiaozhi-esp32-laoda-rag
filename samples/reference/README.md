# 参考音频处理配方（用于声音复刻 / 零样本克隆）

> 这里**不放任何他人声音素材**，只放"怎么处理自己的素材"的方法与脚本。
> 结论优先：**干净度 > 长度 > 微调**。一段 5 秒干净人声，效果胜过长 30 秒带 BGM 的素材。

## 一、硬性要求

| 项 | 要求 | 原因 |
|---|---|---|
| 时长 | **4~10 秒**（推荐 5 秒）| 太短音色不稳，太长易混入情绪/停顿 |
| 背景音 | **无音乐、无混响、无环境噪声** | BGM 会被人声一起复制进音色 |
| 说话人 | 单人，口齿清楚，语速自然 | 多人对话会让模型学成"平均音" |
| 内容 | 一句完整的话（含标点感），不要口号式喊叫 | 避免学出夸张语调 |
| 采样率 | 32 kHz 单声道（喂 GPT-SoVITS 最省事）| 其他采样率要重采样，容易引入伪影 |

## 二、处理步骤

```text
原始素材(mp4/wav/mp3)
  ├─① 人声分离（有 BGM 时必做）→ UVR / demucs，取 vocals 轨
  ├─② 截取 4~8 秒连续单句（宁短勿杂）
  ├─③ 转 32kHz 单声道 + 响度归一
  ├─④ 静音裁剪（去掉首尾空白）
  └─⑤ 试听复核：确认没有音乐残留、没有爆音
```

脚本：`prepare-reference.ps1`（封装 ③④，需要 ffmpeg）

```powershell
.\prepare-reference.ps1 -In my-record.mp4 -Out ref-zh.wav -Seconds 6
```

> **BGM 去除必须用专门的人声分离工具**（UVR / demucs）。ffmpeg 只能做重采样与裁剪，
> 频道相减那类技巧对立体声流行歌有效、对人声素材基本无效。

## 三、质量自检：BGM 残留怎么判断

分离后听三处：**句首、句中停顿、句尾**。如果停顿处还能听到旋律残留，说明没分离干净。

本项目当初的参考音频测得 **BGM 残留 0.107**（越低越好，0 附近最理想），
那段素材经二次清洗后才可用 —— **这一步偷懒，后面怎么调参数都救不回来**。

## 四、GPT-SoVITS 参数（实测）

| 参数 | 值 | 说明 |
|---|---|---|
| 配置 | v4 官方基线（`s1v3.ckpt` + `gsv-v4-pretrained/s2Gv4.pth`）| **不微调** |
| `sample_steps` | **4** | 8 步在短句上 RTF > 1 会卡 |
| `PROMPT_LANG` | `zh` | 与参考音频语言一致 |

**实测结论**：在这批素材上，**LoRA 微调反而比零样本更差** —— 5 秒干净素材 + 不微调是最优解。

## 五、云端复刻 vs 本地克隆

| 路线 | 做法 | 适用 |
|---|---|---|
| 云端（cosyvoice）| 控制台上传音频 → 得到 voiceId → 填 `voiceName = 模型:voiceId` | 有网、想省事；本项目两个角色走这条 |
| 本地（GPT-SoVITS）| 参考音频 + `PROMPT_LANG` + 4 步采样 | 断网、无限量、可微调 |

两条路对**素材的要求完全一样** —— 所以本配方两种都适用。

## 六、不要用的素材

- 直播/视频里的连续发言（有观众声、笑声、混响）
- 带背景音乐的片段
- 影视台词（有情绪表演，学出来很怪）
- 他人声音（**版权与声音权问题**，本项目不提供此类素材）
